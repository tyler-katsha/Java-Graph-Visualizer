Java Graph Visualizer

Java Graph Visualizer is an interactive Java GUI application designed to visually represent graphs in a clean and intuitive way. It allows users to explore nodes and edges interactively, making it easier to understand graph structures and relationships.

✨ Features

Interactive visualization of nodes and edges

Smooth node interaction (dragging and repositioning)

Clean and simple GUI design

Screenshot / image-saving feature to export the current graph view

Beginner-friendly structure, ideal for learning graph concepts

🖼 Image Export

The application includes an image-saving feature that allows users to capture the current graph visualization as a screenshot. This makes it easy to save, share, or document graph layouts.

🛠 Technologies Used

Java

Java Swing / AWT (GUI)

🚀 Future Improvements

This project is still a work in progress. Planned features include:

Enhanced interactivity

Implementation of core graph algorithms (e.g., BFS, DFS, shortest paths)

Improved UI/UX and customization options
